# 🍽️ Food Waste Reduction Solution

## 📌 Project Overview
Food Waste Reduction Solution is a web-based project designed to spread awareness about food wastage and promote sustainable practices. The application highlights the causes of food waste, prevention methods, and encourages food donation to help reduce hunger and environmental damage.

---

## 🎯 Objectives
- Create awareness about food wastage and its impact
- Educate users on prevention techniques
- Promote food donation and responsible consumption
- Encourage sustainable and eco-friendly practices

---

## 🛠️ Technologies Used
- **HTML5** – Structure of the web pages  
- **CSS3** – Styling and responsive layout  
- **Git & GitHub** – Version control and hosting  

---

## ✨ Features
- Clean and user-friendly interface  
- Sections explaining causes and solutions of food waste  
- Donation awareness section  
- Responsive design for mobile and desktop devices  
- Simple and easy navigation
